📄
Доп. документы для закрытия с ЗС
Документы для выплаты КВ и закрытия сделки с застройщиком
⚠️
Важно
Если документов хватает для выплаты КВ, но не хватает для закрытия с ЗС — выплату КВ не блокируем. Заявку передаем на оплату, а недостающий документ продолжаем дожимать параллельно.
📌
Первично запрашиваем у агента полный пакет документов
Сразу отправляем список документов, которые нужны и для выплаты КВ, и для закрытия сделки с ЗС: акт, направление и другие документы по условиям застройщика.
Пакета хватает для выплаты КВ?
✓ Да
Передаем заявку коллегам для оплаты КВ.
✗ Нет
Работаем по стандартному флоу запроса документов до получения пакета для оплаты.
💸
Документов хватает для выплаты КВ, но не хватает для закрытия с ЗС
Агенту пишем, что пакет достаточен для оплаты, но для закрытия с застройщиком нужен недостающий документ.
Для выплаты вознаграждения документов достаточно и мы уже взяли их в работу👌
Но для закрытия с Застройщиком необходим еще — «Документ», просьба прислать его в чат.

Скоро отправим на согласование застройщику: обычно 3–5 дней, но если будет шанс ускорить, мы это сделаем.

Если что-то не так, мы вам сообщим.
🧩
Создаем две задачи
Одна задача создается автоматически по ризону, вторая — ручная контрольная задача на запрос недостающего документа.
Сделка: согласование вознаграждения с ЗС Создается автоматически по ризону и передается на вторую линию.
Бронирование: запрос документов у агента Создаем вручную со сроком через 1 неделю.
Через неделю документ пришел?
✓ Да
Передаем документ по нужному флоу и закрываем ручную задачу «Бронирование: запрос документов у агента» как ошибочную.
✗ Нет
Берем задачу в работу и звоним агенту.
📞
Звонок агенту по недостающему документу
Напоминаем, какой документ нужен для закрытия с ЗС, и фиксируем дальнейшие действия.
Дозвонились?
✓ Да
Берем конкретный срок, фиксируем договоренности в чате и переносим задачу на согласованную дату.
✗ Нет
Переносим задачу на 2 часа и звоним повторно.
После повторного звонка есть ответ?
✓ Да
Возвращаемся к сценарию «Дозвонились»: срок, фиксация в чате, перенос задачи.
✗ Нет
Запрашиваем документ в чат и ставим задачу через 3 дня.
💬
Запрос документа в чат
Пишем агенту, какой документ нужен для закрытия с ЗС, и ставим контроль через 3 дня.
Не смогли до Вас дозвониться и напоминаем:
Для закрытия сделки с застройщиком нам не хватает документа: [указать документ].
Просьба направить документ в чат.
Без него мы не сможем закрыть сделку с ЗС.
⏱ Контроль через 3 дня
Через 3 дня агент ответил?
✓ Да
Ориентируемся на сроки в ответе агента и переносим задачу на указанную дату.
✗ Нет
Передаем агента на АСД через тред, не через файл. Тред обязательно отображаем в истории заявки.
🔴
После передачи на АСД
Фиксируем тред в истории заявки и переносим задачу еще на 1 неделю для повторной проверки статуса.
⏱ Следующий контроль через 1 неделю
🔎
Передача полного пакета на 2 линию и проверка ДДУ
Участники сделки · Объединение заявок · Проверка дублей
Полный пакет считается предоставленным в дату отправки документов агентом в чат.
Реквизиты в полный пакет не входят.
📄
В заявку поступил ДДУ
Открываем документ и проверяем количество участников, указанных в ДДУ.
В ДДУ больше одного участника?
✓ Да
Сверяем всех участников ДДУ с участниками сделки в АРМе.
✗ Нет
Переходим к проверке полного пакета и передаче на вторую линию.
Все участники добавлены в сделку?
✓ Да
Дополнительный поиск заявок не требуется.
✗ Нет
Проверяем, подавались ли заявки по отсутствующим участникам.
🔍
Ищем заявки отсутствующих участников
Поиск выполняем последовательно:
  1. Сначала — по полному ФИО.
  2. Если не нашли — по фамилии и имени среди заявок этого же агента.
Заявки участников найдены?
✓ Да
Объединяем участников и заявки в одну главную сделку.
✗ Нет
Проверяем данные вручную и не закрываем заявки без подтверждения.
🔗
Формируем одну главную сделку
Главной оставляем сделку, по которой агент прислал документы. Добавляем в нее всех участников ДДУ, а остальные найденные заявки закрываем в пользу успешной сделки.
📦
Передаем полный пакет на вторую линию
Пакет документов передаем только по одной — главной — сделке.
🧪
Вторая линия проверяет ДДУ на дубли
Проверка выполняется перед отправкой документов на согласование застройщику.
🔎 Открыть инструмент «Проверка ДДУ»
Инструмент нашел дубли?
✓ Да
Проверяем все совпадения вручную в АРМе.
✗ Дублей нет
Передаем документы на согласование застройщику.
🖥️
Ручная проверка совпадений в АРМе
Проверяем каждую найденную заявку и определяем, является ли совпадение фактическим дублем.
✅
После проверки передаем на застройщика
Отправляем документы на согласование только после того, как убедились, что фактических дублей нет или найденные совпадения корректно обработаны.
